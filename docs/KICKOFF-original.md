# 공일모바일 — 킥오프 인수인계 (2026-07-27, SETKORA 세션에서 작성)

새 세션 시작 시 이 문서를 먼저 읽을 것. 곽민준 사장님의 **오프라인 핸드폰 매장**을
SETKORA 플레이북(풀자동화 온라인 플랫폼)으로 온라인화하는 프로젝트다.

## 확정된 결정 (사장님 승인)
- **브랜드**: 공일모바일 (신규 브랜드, "01컴퍼니" 계열 네이밍)
- **타깃**: 한국인 + 외국인 둘 다 (ko 우선 → 다국어는 SETKORA 13개 언어 엔진 재사용)
- **취급 범위(전부)**: 통신사 개통(신규·번호이동·기변) · 알뜰폰/유심/eSIM · 자급제+요금제 조합 · 중고폰 판매·매입
- **접수 방식**: 매장 방문 예약 (비대면 개통은 2단계로 미룸 — 본인확인 규제 무거움)
- **도메인**: gongilmobile.com ✅ RDAP 등록가능 확인(2026-07-27), gongil-mobile.com도 가능.
  .kr/.co.kr(공일모바일.kr 등)은 가비아에서 확인 필요. 01mobile.com은 이미 등록됨.

## 아키텍처 — SETKORA 이식표
| SETKORA (참고: ../skyrental-toss) | 공일모바일 |
|---|---|
| 상품 카탈로그 (js/data.js) | 기기(신규·자급제·중고) + 요금제(통신사·알뜰폰) DB |
| 30초 매칭소 (finder) | 요금제 스무고개 — 사용량·가족결합·기변/번이 문답 |
| 뭉게 AI 상담 (functions/api/chat.js) | 동일 엔진 포크 — 개통·요금제·유심 상담 |
| 접수→텔레그램 릴레이 (rental-intake) | 방문 예약(날짜·시간·희망 기기) → 텔레그램 |
| 가이드 SEO 공장 (tools/build-guides) | 요금제·자급제·알뜰폰 가이드 + 네이버 플레이스 로컬 SEO |
| 요정 빌리지 추천 | 친구 소개 예약 → 방문 확인 보상 (2단계) |
| 일일 헬스체크·주간 리포트 루틴 | 동일 패턴으로 신설 (SETKORA 루틴은 SETKORA 세션 소유) |

## ⚠️ 규제 가드레일 (SETKORA hedge 문화 계승)
- 단통법 폐지(2025.7) 후에도 **허위·과장 지원금 광고 규제는 존속** — 온라인 가격 표기는
  항상 "예상 월 납부액 **범위** + 최종가는 매장에서 확정" 구조. 확정가·최저가 단정 금지.
- 중고 매입가도 "모델·상태 기준 예상 범위"로만 표기.
- 개인정보: 신분증·본인확인 정보는 온라인 수집하지 않음(방문 예약 모델의 이유).
  예약 정보는 SETKORA와 동일하게 서버 무저장→텔레그램 릴레이 원칙.

## 기술 방침
- 이 폴더(`gongil-mobile/`)에 구축. 같은 모노레포, **별도 Cloudflare Pages 프로젝트 + 별도 D1**.
- 배포 체인·검증 습관은 `../skyrental-toss/CLAUDE.md` 참조 (cwd 함정, 캐시버스터 검증,
  stamp-assets 패턴, 13개 언어 규칙, 번역 병렬 에이전트 패턴 전부 재사용 가능).
- **시크릿은 절대 커밋 금지.** Cloudflare API 토큰·텔레그램 봇 토큰은 사장님이 새 세션에
  직접 전달해야 함 (SETKORA와 같은 계정이면 기존 토큰 재사용 가능 — 사장님에게 요청할 것).

## 착수 전 사장님에게 받아야 할 인풋 (2026-07-27 현재 미수령)
1. 매장 정보: 사업자등록상 상호·주소·영업시간·전화번호 (예약·푸터·네이버 플레이스용)
2. 취급 통신사 코드(SKT/KT/LGU+ 중)와 알뜰폰 브랜드 리스트
3. 대표 기기 20~30종 + 주력 요금제 리스트 + **정책표(단가) 샘플 1장**
   → 일 단위 시세 변동은 관리자 페이지에서 사장님이 숫자만 갱신하는 구조로 설계할 것
4. 도메인 구매 확정 (gongilmobile.com 추천 + .kr 세트)
5. 중고 매입 기준표 (있으면)
